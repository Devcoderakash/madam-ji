# Madam Ji's Dream

This is an interactive 3D love story website, built with React, Vite, and TanStack Start. It features a personalized and magical experience.

## Getting Started

### Prerequisites
Make sure you have [Bun](https://bun.sh/) installed.

### Installation

Install the dependencies:

```bash
bun install
```

### Development

Run the development server:

```bash
bun run dev
```

The application will start on `http://localhost:8080`.

### Build

To build the application for production:

```bash
bun run build
```

## Technologies Used
- React
- Vite
- TanStack Start
- TailwindCSS
- Framer Motion
- Shadcn UI
